## 🔬 Peer-Reviewed Research

### 📄 [IEEE INDICON 2024](https://ieeexplore.ieee.org/document/10958261) Low-Light Traffic Sign & Signal Detection via YOLOv9 & GANs

* **Focus**: Restoring visual fidelity and maintaining high object detection accuracy in severe low-light and nighttime driving environments.
* **Architecture**: Integrated an image-to-image translation GAN for real-time visual restoration with **YOLOv9** (utilizing GELAN and Programmable Gradient Information) for bounding-box classification.
* **Impact**: Mitigated gradient degradation across deep feature maps, significantly outperforming baseline single-stage detectors on degraded frames.
